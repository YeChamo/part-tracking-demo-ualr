UALR PART TRACKING DEMO - THIRD-PARTY NOTICES

This file records the local build inputs and the license/notice files available
in those installed distributions. Exact supplied notices are copied under
licenses\<package>\. Each package has METADATA.txt and SOURCE.txt. The machine-
readable licenses\inventory.json records logical source locations, versions,
copied-file hashes, and local model/inference source provenance. Workstation
user/profile prefixes have been removed from generated provenance records;
the copied upstream license and notice texts are unchanged. Existence and
source-match fields record checks made when the files were originally copied.

The original runtime's installed ONNX Runtime came from the onnxruntime-gpu
distribution. This application selects CPUExecutionProvider; the packaging recipe

onnxruntime distribution at the same version; the retained onnxruntime-gpu
metadata documents the original build input rather than a GPU requirement.

license includes notices for its bundled numerical/runtime components; additional
