This file records the local build inputs and the license/notice files available
in those installed distributions. Exact supplied notices are copied under

the copied upstream license and notice texts are unchanged. Existence and
source-match fields record checks made when the files were originally copied.

The current CPU build recipe installs torch from
https://download.pytorch.org/whl/cpu before the pinned base requirements.
These export dependencies are included in the portable application. Their
installed distribution metadata and supplied license/notice files are copied
into the packaged runtime's corresponding .dist-info directories. The older
licenses\inventory.json predates these additions and is not their inventory.

The default build uses the CPU onnxruntime 1.23.2 distribution. Optional
Build.ps1 -TensorRT replaces it with onnxruntime-gpu 1.23.2 and installs
tensorrt-cu12 10.9.0.34, retaining their GPU provider/runtime libraries. Those
optional NVIDIA components remain subject to their supplied upstream license
terms and require compatible station hardware/drivers. No NVIDIA GPU is
available on this development laptop; no successful hardware TensorRT run is
claimed by these notices. An advertised ORT provider is not a hardware test.

YOLOX class; the white photo crop does not provide that prediction.
