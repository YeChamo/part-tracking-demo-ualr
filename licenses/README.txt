LICENSE AND PROVENANCE COPIES

Each package directory contains its locally installed METADATA.txt, a SOURCE.txt
with the logical source location/version, and copies of available license/notice
files. Personal workstation prefixes were removed from generated SOURCE.txt and
inventory records. Upstream license, notice, and metadata texts are unchanged.
Original dist-info and package-relative paths are preserved inside the directory
so similarly named notices do not overwrite each other. Files were copied
verbatim; inventory.json records SHA-256 for the copied notice files. Source
existence and source-match flags record the original copy-time checks.

python\LICENSE.txt is the license accompanying the CPython 3.11.5 base runtime.
PyInstaller's COPYING.txt includes the bootloader exception. OpenCV and ONNX
Runtime third-party notices and NumPy's bundled-library notices are preserved.

See ..\THIRD_PARTY_NOTICES.txt for component versions, runtime scope, and exact
limitations of the locally available Qt/model/source license metadata. This
folder preserves supplied evidence rather than inventing unavailable notices.
